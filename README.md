# Flutter Riverpod Template

Feature-First Flutter + Riverpod 脚手架。架构规范、分层约定与提交门禁见 [AGENTS.md](AGENTS.md)。

```bash
flutter pub get
flutter gen-l10n
dart run pigeon --input pigeons/app_platform.dart
dart run build_runner build
flutter run
```

Widget Preview：VS Code 侧边栏打开 **Flutter Widget Preview**。新组件用 `@AppPreview`，步骤见 [AGENTS.md](AGENTS.md)。
